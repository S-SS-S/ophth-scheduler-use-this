# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue. Report them privately to `Sultan.Alhassan@hotmail.com` with:

- the affected page or file
- steps to reproduce
- expected and observed behavior
- browser and device
- any proof-of-concept that does not expose user data

## Security principles

- The scheduler should not collect identifiable health information.
- Medical inputs should remain in browser memory only.
- Third-party scripts should be minimized and reviewed.
- External links must use HTTPS.
- Changes should pass automated checks before deployment.
- Secrets and tokens must never be committed to the repository.

## Supported version

Only the current production version at `www.opth.net` is supported.
